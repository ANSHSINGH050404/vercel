# vercel

Vercel deployment experiments and Next.js hosting utilities.

## Stack

Turborepo, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/vercel.git
cd vercel
bun install
bun run dev   # or: bun run start
```
